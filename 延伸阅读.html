    14. 延伸阅读

    本文介绍了 Java 语言，以及编写分层应用程序、网络客户端和服务器以及 Web 服务时最常用的库。下面是在此基础上进一步深入的主要主题。

    14.1. 处理 XML 文档

    JSON 已在很大程度上取代 XML 用于数据交换，但 XML 仍在使用（如 Maven 的 [pom.xml] 这样的配置文件、文档格式以及现有的 SOAP 服务）。JDK 在 [javax.xml] 包中提供了多种 API：

    • DOM （[DocumentBuilder]、[Document]、[Element]）：文档作为树加载到内存中，然后对其进行遍历和修改；
    • StAX （[XMLStreamReader]、[XMLStreamWriter]）：文档被即时读取或写入，无需完整加载到内存中；
    • XPath （[javax.xml.xpath]）用于查询文档，XSLT （[javax.xml.transform]）用于转换文档。

    除 JDK 之外，Jakarta XML Binding 库（JAXB）将 Java 类映射到 XML 文档，就像 Jackson 对 JSON 所做的那样（第 5 章）；Jackson 也可以使用其 [jackson-dataformat-xml] 模块读写 XML。

    14.2. Web 应用程序

    第 13 章只涉及 Web 服务（生成数据的应用程序）。对于生成 HTML 页面的 Web 应用程序，Java 生态系统提供了：

    • Spring MVC 配合 Thymeleaf 等模板引擎：服务器端渲染的页面；作者编写了课程 《Spring MVC Web 框架分步入门》（2026 年 9 月）；
    • Jakarta EE （以前称为 Java EE），这套规范包括 servlet、JPA（Jakarta Persistence，第 11 章）、CDI（依赖注入）和 JAX-RS（REST 服务），由 WildFly、Payara 或 Open Liberty 等应用服务器实现；
    • 其他更轻量或更新的框架：Quarkus、Micronaut、Helidon、Javalin；
    • 用 JavaScript 编写的、使用 Java Web 服务的界面（Vue.js、Angular、React）；作者编写了课程 《Vue.js 框架分步入门》（2026 年 9 月）。

    14.3. 桌面和移动应用程序

    本文不涉及图形用户界面：如今，管理类应用程序大多使用 Web 界面构建。JDK 仍然提供 Swing 库，而 JavaFX 库（自 Java 11 起由 OpenJFX 项目单独发布）可用于开发现代桌面界面。第 7 章（事件监听器）和第 9 章（异步编程）所讲的概念可直接应用于此。在移动设备上，Android 应用程序用 Java 编写，或者越来越多地用 Kotlin 编写，Kotlin 也是一种为 Java 虚拟机生成字节码的语言。

    14.4. 测试

    第 6 章介绍了 JUnit。通常还会辅以：

    • AssertJ 库，它提供可读性更好的断言（[assertThat(list).hasSize(7).contains(x)]）；
    • Mockito 库，它为被测层所依赖的各层创建“mock”（模拟对象）；
    • Testcontainers，它在集成测试期间于 Docker 容器中启动真实的数据库（MySQL、PostgreSQL……）；
    • Spring Boot 测试工具（[@SpringBootTest]、[MockMvc]），用于在不部署 Web 服务的情况下对其进行测试。

    14.5. 性能

    Java 虚拟机即时编译字节码，并在执行期间对其进行优化，从而使长时间运行的程序具有出色的性能。以下是一些更进一步的工具：

    • JMH 工具（“Java Microbenchmark Harness”），用于精确测量代码性能，并考虑虚拟机的预热时间；
    • JDK Flight Recorder 和 JDK Mission Control，用于记录和分析程序在生产环境中的行为；
    • 使用 GraalVM Native Image 进行提前编译为本地代码：生成几毫秒内即可启动的独立可执行文件，代价是对反射有所限制；Spring Boot 和 Quarkus 都可以生成这种可执行文件；
    • 垃圾回收器的选择（默认为 G1，对于大内存堆需要极短停顿时则用 ZGC）。

    14.6. 部署

    Java 程序可以通过多种方式部署：作为由机器上安装的 JDK 执行的 [.jar] 归档文件（[java -jar application.jar]；Spring Boot 会生成包含其所有库的独立 [.jar] ），作为内嵌一个仅保留所需内容的精简虚拟机的独立应用程序（JDK 的 [jlink] 和 [jpackage] 工具），或者在 Docker 容器 中（Spring Boot 通过 [mvn spring-boot:build-image] 直接生成容器镜像）。
