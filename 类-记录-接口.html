    4. 类、记录、接口

    4.1. 通过示例理解对象

    4.1.1. 概述

    现在我们通过示例来探索面向对象编程。对象是一种实体，它包含定义其状态的数据（称为字段、属性等）和函数（称为方法）。对象是根据称为类的模板创建的。例如，名为 [C1] 的类声明了两个字段 [Type1 p1;] 和 [Type2 p2;]，以及两个方法 [Type3 m3(...) { ... }] 和 [Type4 m4(...) { ... }]，它们都包含在声明 [public class C1 { ... }]的花括号之内。

    从类 [C1]可以创建许多对象，例如 [o1]、[o2]……它们都具有字段 [p1]、[p2]……以及方法 [m3]、[m4]……不过，它们的 [pi]字段会有不同的值，因此每个对象都有自己独特的状态。如果 [o1] 是类型为 [C1]的对象，[o1.p1] 指的是 [p1]字段，即 [o1]，的字段，而 [o1.m3(...)] 指的是对 [m3]方法（即 [o1]的方法）的调用。

    我们来考虑第一个对象模型：类 [Person]。

    public class Person {
    // 属性（字段）
    private String firstName = "";
    private String lastName = "";

    public void initialize(String p, String n, int age) {

    • 第 1 行：该类是公共的（[public]）：所有其他类都可以使用它。它不属于任何包——更准确地说，它属于未命名包；包将在本章末尾讨论；
    • 第 3–5 行：类的三个字段。两个字符串都用空字符串初始化：否则，创建对象时它们会被设为 [null] （未初始化的对象字段被设为 [null]，数值字段被设为 0，布尔字段被设为 [false]）；
    • 第 8–12 行：设置对象状态的方法；
    • 第 15–17 行：显示对象状态的方法。[IO] 是我们在上一章使用过的 Java 25 控制台输入/输出类。

    这里我们看到的是一个类的定义——也就是一种数据类型。当我们创建这种类型的变量时，称之为对象或类的实例。因此，类是构造对象所用的模板。按照惯例，类名以大写字母开头（[Person]），而字段名或方法名以小写字母开头（[firstName]、[initialize]）。

    类的成员可以是数据（字段）或方法（函数）。这些成员可以带有下列关键字之一：

    关键字
    访问权限
    [private]
    私有成员只能被类的内部方法访问
    （无）
    如果没有指定关键字，该成员可以被同一包中任何类的方法访问。这是默认访问权限，称为“包访问权限”
    [protected]
    受保护成员可以被同一包中类的方法以及派生类的方法访问（见下文继承的概念）
    [public]
    公共成员可以被任何方法访问，无论该方法是否定义在该类之内

    一般来说，类的数据声明为私有，而它的方法声明为公共。这意味着对象的使用者（程序员）：

    • 不能直接访问对象的私有数据；
    • 可以调用对象的公共方法，包括那些提供对其私有数据访问的方法。

    声明 [private]、[protected]和 [public] 成员的顺序是任意的。请注意，默认访问权限并不是 private：不带关键字声明的字段对包中的所有类都是可见的。因此，你必须记得写 [private]。

    4.1.4. initialize 方法

    [initialize]方法的作用是什么？由于 [lastName], [firstName],和 [age] 是 [Person]类的私有成员，在主程序中写出的类似 [p1.firstName = "Jean";]的语句是无效的。编译器会拒绝它：

    1
2
3
4
5
6
    > java Main.java
Main.java:4: error: firstName has private access in Person
    p1.firstName = "Jean";
      ^
1 error
error: compilation failed

    编译器消息是英文的：JDK 的消息没有法语翻译。它指明了出错的文件和行号，然后用插入符号标出出错位置。我们需要通过公共方法来初始化类型为 [Person] 的对象。这就是 [initialize] 方法的作用。我们将写 [p1.initialize("Jean", "Dupont", 30);]。这种语法是有效的，因为 [initialize] 是公开可访问的。

    4.1.5. new 运算符

    不过，还缺少一些东西。声明 [Person p1;] 把 [p1] 声明为对 [Person] 类型对象的引用。这个对象尚不存在，因此 [p1] 没有被初始化。当我们接着写 [p1.initialize("Jean", "Dupont", 30);]时，我们调用了 [initialize] 方法，该方法属于由 [p1]引用的对象。然而，这个对象并不存在，编译器会报告错误：局部变量 [p1] 尚未被赋值。

    1
2
3
4
5
6
    > java Main.java
Main.java:4: error: variable p1 might not have been initialized
    p1.initialize("Jean", "Dupont", 30);
    ^
1 error
error: compilation failed

    如果我们写 [Person p1 = null;] 后接 [p1.initialize("Jean", "Dupont", 30);]，就是用关键字 [null] 显式地表明变量 [p1] 尚未引用任何对象。编译器接受该程序，但在运行时，方法调用会触发 [NullPointerException]异常：

    1
2
3
    > java Main.java
Exception in thread "main" java.lang.NullPointerException: Cannot invoke "Person.initialize(String, String, int)" because "<local1>" is null
    at Main.main(Main.java:4)

    自 Java 14 起，异常消息会指明哪个操作失败；[<local1>] 指的是局部变量 [p1]，它的名称没有被内存中的编译保留下来。要让 [p1]引用一个对象，必须写 [Person p1 = new Person();]。

    这会创建一个尚未初始化的 [Person]类型的对象：它的字段具有默认值——这里，[lastName] 和 [firstName], 为空字符串，[age]为 0。现在 [p1] 引用了一个对象，该对象的初始化语句 [p1.initialize("Jean", "Dupont", 30);]，就是有效的了。

    4.1.6. this 关键字

    我们来看 [initialize]方法的代码：

        this.firstName = p;

    语句 [this.firstName = p;] 表示当前对象（[firstName] ）的字段 [this]被赋予值 [p]。关键字 [this] 指当前对象：即执行该方法所针对的那个对象。我们怎么知道这一点？来看调用程序中由 [p1]引用的对象是如何被初始化的：[p1.initialize("Jean", "Dupont", 30);]。被调用的是对象 [initialize] 的 [p1] 方法。当在这个方法内部引用对象 [this]时，它实际上指的是对象 [p1]。

    当对象的某个方法引用该对象的字段 [a] 时，记法 [this.a] 是隐含的：[initialize] 方法本来可以写成 [firstName = p;] 和 [lastName = n;]。当标识符发生冲突时，必须显式使用 [this] 。语句 [this.age = age;] （第 11 行）就是这种情况，其中 [age] 既指当前对象的字段，也指方法接收的参数 [age]。在方法中，单独的名称 [age] 指的是参数；字段必须写成 [this.age]。

    4.1.8. 紧凑源文件

    对于一个简短的示例来说，使用包含多个文件的文件夹显得过于庞大。因此，与上一章一样，我们编写一个紧凑源文件（Java 25）：即包含方法[void main()]、可能还有其他方法和字段以及程序所需类的文件。我们使用源代码启动器来运行它：[java Classes01.java]。

    理解编译器如何处理这样的文件很重要。它会把文件包装在一个隐式类中，该类以文件名命名（[Classes01]）：文件中的方法和字段成为这个类的成员，而文件中声明的类则成为这个隐式类的嵌套类。对该文件进行显式编译可以证明这一点：

    1
2
3
4
    > javac -d classes Classes01.java
> ls classes
Classes01$Person.class
Classes01.class

    因此，文件[Person] 类在[Classes01.java] 中的完整名称是[Classes01$Person]。这会带来两个后果，我们将在示例中遇到：

    • 一个类与它所包含的类共享各自的私有成员：紧凑文件中的[main]方法可以访问该文件中各个类的私有字段。要确保私有字段无法从其类外部访问，就必须像在[Persons]文件夹中那样，把该类放在它自己的文件中；
    • 普通的嵌套类是内部类：它的对象与外围类的某个对象绑定。只要对象是由文件中的方法创建的，这一点就不明显，但静态方法（见关于类成员的一节）无法创建它们。这时我们把嵌套类声明为[static]。后面要讨论的记录和接口总是静态的。

    最后，紧凑文件会自动导入[java.base]模块中所有的公共类：[List]、[ArrayList]、[BigDecimal]、[Objects]……都可以在其中直接使用，无需[import]子句。而对于常规文件，例如[Person.java]，则并非如此，我们将会看到。

}

    • 第 19–23 行：上一段中的[initialize]方法；
    • 第 26–30 行：第二个方法，[initialize]。

    第二个方法的参数是对某个人的引用（[p]）。该人的字段（[p]）随后被赋给当前对象（[this]）。请注意，方法[initialize] 可以直接访问对象[p] 的字段，尽管这些字段是私有的（第 27–29 行）。这一点始终成立：类[C] 的方法可以访问同一个类[C]的所有对象的私有成员。

    4.1.10. Person 类的构造函数

    构造函数是一种与类同名、在创建对象时被调用的方法。它通常用于初始化对象。它是可以接受参数但不返回值的方法，其声明前面不带任何类型（甚至不带[void]）。

    如果类[C] 有一个接受 n 个参数的构造函数，则该类对象的声明和初始化可以写成[C object = new C(arg1, arg2, ... argn);]的形式，也可以分两步完成：先写[C object;]，稍后再写[object = new C(arg1, arg2, ... argn);]。

    当类[C] 有一个或多个构造函数时，必须使用其中一个构造函数来创建该类的对象。如果类[C] 没有构造函数，则它有一个什么也不做的无参默认构造函数，对象的字段保持其初始值。在前面的程序中就是这种情况，我们当时写的是[new Person()]。

class Person {
    // 属性
    private String firstName;
    private String lastName;
    private int age;

    // 主构造函数
    public Person(String firstName, String lastName, int age) {
        this.firstName = firstName;
        this.lastName = lastName;
        this.age = age;
    }

    // 拷贝构造函数：它调用主构造函数
    public Person(Person p) {
        this(p.firstName, p.lastName, p.age);
    }

    // 无参构造函数：它同样调用主构造函数
    public Person() {
        this("?", "?", 0);
    }

    // 此人的身份信息
    public void identify() {
        IO.println("[" + firstName + ", " + lastName + ", " + age + "]");
    }
}
    • 第 18–22 行：“主”构造函数初始化三个字段。由于它的参数与字段同名，因此使用[this]来区分字段；
    • 第 25–27 行：复制构造函数。语句[this(p.firstName, p.lastName, p.age);] 调用同一个类中接受三个参数的构造函数：[String]、[String]和[int]。这称为构造函数链式调用。这样，初始化代码只需写一次；

    该构造函数接收四个参数（[firstName]、[lastName]、[age]、 [section]），并使用语句[super(firstName, lastName, age);] （第 3 行）把其中三个（[firstName]、[lastName]、[age]）传递给它的父类，这里即类[Person]。我们知道这个类有一个构造函数 [Person(String, String, int)]，它将用于使用传入的参数创建一个人。一旦 [Person] 部分构造完成，[Teacher]对象的构造就会通过执行构造函数的其余部分（第 5–7 行）继续进行。

    总之，派生类的构造函数：

    • 通过[super(...)]向其父类传递父类构造自身所需的参数；
    • 使用其他参数初始化它自己的字段。

    我们本来可以选择在类[Teacher] 的构造函数中直接初始化字段 [firstName]、[lastName] 和 [age]，使用类似[this.firstName = firstName;] 的语句。这是不可能的，原因有二。首先，私有字段 [firstName]、[lastName] 和 [age] 只能被 [Person] 类的方法访问。所有其他对象，包括像本例中这样的派生类的对象，都必须通过公共（或受保护）成员来访问它们。如果类 [Person] 把这些字段声明为 protected（*[protected]*)，情况就会不同：这样派生类就可以直接访问它们。此外，对象的 [Person] 部分无论如何都必须由 [Person] 类的构造函数来构造：如果没有调用[super(...)]，编译器会插入对[super()] 的调用——即父类的无参构造函数。然而，类 [Person] 并没有这样的构造函数。如果删除[super(firstName, lastName, age);]语句，编译器会报告如下错误：

    4.2.4. 多态

    考虑一个类层次结构：C0 ← C1 ← C2 ← … ← Cn，其中 Ci ← Cj 表示类 Cj 派生自类 Ci。这意味着类 Cj 具有类 Ci 的所有特性，外加一些额外的特性。设 Oi 为类型 Ci 的对象。当 j > i 时，写[Oi = Oj] 是合法的。确实，通过继承，类 Cj 具有类 Ci 的所有特性，外加一些额外的特性。因此，类型 Cj 的对象 Oj 包含一个类型 Ci 的对象。操作[Oi = Oj] 使类型为 Ci 的变量 Oi 引用对象 Oj：通过它只能访问类 Ci 中定义的成员。

    类 Ci 的变量 Oi 实际上不仅可以引用类 Ci 的对象，还可以引用从类 Ci 派生的任何对象，这一事实称为多态：变量引用不同类型对象的能力。

    4.2.6. Object 类和 toString 方法

    类[java.lang.Object]是所有 Java 类的“父”类。因此，当你写[public class Person]，你实际上隐式地写了[public class Person extends Object]。

    类[Object]定义了所有对象都会继承的几个方法：

    • [String toString()]：返回对象的文本表示。默认情况下，它是对象的类名，后面跟着字符[@] 和一个以十六进制书写的哈希码；

    接口是一组构成契约的方法声明。选择实现接口的类承诺为接口中定义的所有抽象方法提供实现。编译器会验证这一实现。

    例如，下面是 JDK 的[java.util.Iterator<E>]接口的（简化）定义，它允许你遍历集合中的元素：[public interface Iterator<E> { boolean hasNext(); E next(); }]。接口的方法仅由其签名定义，后面跟一个分号：它们没有代码，并且隐式地是 public 和 abstract 的。为接口方法提供代码的是实现该接口的类。名为[C] 的类使用关键字[implements]声明它实现该接口：[public class C implements Iterator<String>]，然后它必须定义两个公共方法[public boolean hasNext() { ... }] 和[public String next() { ... }]。

public class ListOfGrades implements IStats {
    // 字段
    private final String subject;
    private final List<Grade> grades;
    // 存储的平均值和标准差（null：尚未计算）
    private Double average;
    private Double standardDeviation;

    public ListOfGrades(String subject, List<Grade> grades) {
        this.subject = subject;
        this.grades = grades;

    // getter
    public String getSubject() {
        return subject;
    }

    public List<Grade> getGrades() {
        return grades;
    }

    // 添加一个成绩
    public void add(Grade grade) {
        grades.add(grade);
        // 平均值和标准差将需要重新计算
        average = null;
        standardDeviation = null;
    }

    // 成绩的平均值：首次请求时计算
    @Override
    public double average() {
        if (average == null) {
            average = computeAverage();
        }
        return average;
    }

    // 成绩的标准差：首次请求时计算
    @Override
    public double standardDeviation() {
        if (standardDeviation == null) {
            standardDeviation = computeStandardDeviation();
        }
        return standardDeviation;
    }

    private double computeAverage() {
        if (grades.isEmpty()) {
            return -1;
        }
        double sum = 0;
        for (Grade grade : grades) {
            sum += grade.value();
        }
        return sum / grades.size();
    }

    private double computeStandardDeviation() {
        if (grades.isEmpty()) {
            return -1;
        }
        double m = average();
        double squares = 0;
        for (Grade grade : grades) {
            squares += Math.pow(grade.value() - m, 2);
        }
        return Math.sqrt(squares / grades.size());
    }

    // toString
    @Override
    public String toString() {
        return "subject=" + subject + ", grades=" + grades;
    }
}

class Pair<T> {
    private T first;
    private T second;

    public Pair(T first, T second) {
        this.first = first;
        this.second = second;
    }

    public T getFirst() {
        return first;
    }

    public T getSecond() {
        return second;
    }

    // 交换这两个元素
    public void swap() {
        T temp = first;
        first = second;
        second = temp;
    }

class Generic2 {
    // 交换 T 类型元素数组中的第 i 个和第 j 个元素
    public static <T> void swap(T[] array, int i, int j) {

        array[i] = array[j];
        array[j] = temp;
    }

// T 类型元素的栈
class MyStack<T> {
    // 栈中的元素
    private final List<T> elements = new ArrayList<>();

    // 元素个数
    public int size() {
        return elements.size();
    }

    // 在栈顶添加一个元素
    public void push(T element) {
        elements.add(element);
    }

    // 移除栈顶元素
    public T pop() {
        if (elements.isEmpty()) {
            throw new IllegalStateException("empty stack");
        }
        return elements.removeLast();
    }
}

    4.8.3. 泛型接口：Comparable<T> 和 Comparator<T>

    为了说明泛型接口的概念，我们将按不同的标准对人员数组进行排序。对数组排序的方法是类[sort] 的静态方法[java.util.Arrays]。它是重载的；我们将使用其中两个变体：

    • [Arrays.sort(Object[] array)] 按照其元素的自然顺序对数组排序：这些元素必须实现[Comparable<T>]接口，该接口唯一的方法[int compareTo(T other)]，把当前对象与[other]对象进行比较；
    • [Arrays.sort(T[] array, Comparator<? super T> comparator)] 按照由比较器对象定义的顺序对数组排序，该对象实现了[Comparator<T>]接口，其[int compare(T x, T y)]方法比较两个对象（类型[? super T] 将在下一段解释）。

    4.9. 包

    要在屏幕上输出一行，我们使用[IO.println(...)]语句。如果我们查看 JDK 文档中[IO]类的定义，会发现它属于[java.lang] 包。这意味着它的完整名称是[java.lang.IO] ，我们也可以写[java.lang.IO.println(...)]。[java.lang]包中的类（[String]、[Object]、[Math]、[Integer]……）始终用它们的简单名称来引用。对于其他类，则使用放在文件开头的[import]子句：

    • [import java.util.List;] 从包[java.util]中导入类[List]；
    • [import java.util.*;] 按需导入[java.util]包中所有的公共类；
    • [import module java.base;] （Java 25）导入由[java.base]模块导出的包中所有的公共类（见下文）。紧凑文件隐式地就是这样做的；
    • [import static java.lang.Math.sqrt;] 导入类的静态成员，之后无需指定类名即可使用它：[sqrt(2)]。

    当编译器遇到类的短名称时，它会在当前包和已导入的类中查找。[import]子句不会给程序增加任何东西：它只是避免了写出完整名称。

    创建类时，要把它放在某个包中。包的目的是避免类之间的名称冲突，例如在分发时。设想两家公司 E1 和 E2，分别分发打包在归档文件[e1.jar] 和[e2.jar] 中的类。假设客户 C 购买了这两套类，两家公司都在其中定义了名为[Person]的类。如果公司 E1 在名为[e1] 的包中创建其类，公司 E2 在名为[e2]的包中创建其类，那么这两个[Person] 类就将分别被命名为[e1.Person] 和 [e2.Person]。客户可以导入其中一个，并用完整名称引用另一个。包解决了这种歧义。按照惯例，包名使用小写，并以发布它们的组织的反向域名开头（[com.mysql.cj.jdbc]、[org.hibernate]……）；在我们的示例中，将使用简短的名称。

// 记录：firstName、lastName、age 是它的组件
record Person(String firstName, String lastName, int age) implements HasIdentity {
    // 可以添加方法
    @Override
    public String identity() {
        return "[" + firstName + ", " + lastName + ", " + age + "]";
    }

    // “wither”方法：其中一个组件发生变化的副本
    public Person withAge(int age) {
        return new Person(firstName, lastName, age);
    }
}

        if (age < 0) {
            throw new IllegalArgumentException("age (" + age + ") invalid");
        }
    }

    // 任何其他构造函数都必须调用规范构造函数
    Person(String lastName) {
        this("?", lastName, 0);
    }

    // 返回新的人的方法
    public Person growOlder() {
        return new Person(firstName, lastName, age + 1);
    }

    public String identity() {
        return "[" + firstName + ", " + lastName + ", " + age + "]";

        if (value == null || value.isBlank()) {

    4.14. 处理 null 值

    任何引用类型的变量都可以取值[null]，使用空引用会引发[NullPointerException]异常，这是 Java 中最常见的运行时错误。与 C# 或 Kotlin 等其他语言不同，Java 编译器不区分可以为[null] 的类型和不可以为 null 的类型。不过，JDK 和各种库提供了若干工具来降低这种风险：

    • [Optional<T>]类（Java 8），用作可能不返回任何内容的方法的返回类型；
    • [Objects]类的方法：[requireNonNull] 用于在方法或构造函数的入口处拒绝[null] ，而[requireNonNullElse] 用于提供默认值；
    • 记录意图并由某些分析工具验证的注解。最新的一批注解由一组厂商（Google、JetBrains、Spring……）提出，来自 JSpecify 库：[@Nullable] 用于可以为[null]的类型，而[@NullMarked] 用于类或包，表示其他类型不能为 null。我们将要使用的 Spring Framework 7 就采用了它们。它们需要一个库，因此本章中我们不会使用它们。

void main() {
    Person jean = new Person("Jean", "Dupont");
    jean.setMiddleName("Marie");
    Person[] persons = { jean, new Person("Paul", "Martin") };

        String length = p.getMiddleName() == null ? "null" : String.valueOf(p.getMiddleName().length());
        IO.println(p.getFirstName() + " : middle name=" + middle + ", length=" + length);

    Optional<Person> found = find(persons, "Durand");
    IO.println("Durand found: " + found.isPresent());
    IO.println(found.map(Person::getFirstName).orElse("Durand: person not found"));
    // 使用值之前先测试它是否存在
    found = find(persons, "Martin");
    if (found.isPresent()) {
        IO.println("Martin : " + found.get().getFirstName());
    }
    // ifPresent：仅当存在值时才执行该操作
    find(persons, "Dupont").ifPresent(p -> p.setMiddleName("Louise"));
    find(persons, "Durand").ifPresent(p -> p.setMiddleName("Louise"));
    IO.println(jean.getMiddleName());

    Person martin = find(persons, "Martin").orElseThrow();

    try {
        new Person(null, "Morel");
    } catch (NullPointerException ex) {
        IO.println("Error: " + ex.getMessage());
    }
    // NullPointerException 异常及其详细消息（Java 14）
    try {
        Person lise = new Person("Lise", "Morel");
        IO.println(lise.getMiddleName().length());
    } catch (NullPointerException ex) {
        IO.println("Error: " + ex.getMessage());

    @Override
    public int calculate(boolean married, int nbChildren, int salary) {
        // 计算份额数
        BigDecimal shares = BigDecimal.valueOf(nbChildren).divide(BigDecimal.TWO)
                .add(BigDecimal.valueOf(married ? 2 : 1));
        if (nbChildren >= 3) {
            shares = shares.add(new BigDecimal("0.5"));
        }
        // 计算应税收入和家庭商数
        BigDecimal income = new BigDecimal("0.72").multiply(BigDecimal.valueOf(salary));
        BigDecimal quotient = income.divide(shares, MathContext.DECIMAL128);
        // 查找税率档：如果没有合适的上限，则使用最后一档
        List<TaxBracket> brackets = getTaxBrackets();
        TaxBracket bracket = brackets.getLast();
        for (int i = 0; i < brackets.size() - 1; i++) {
            if (quotient.compareTo(brackets.get(i).limit()) <= 0) {
                bracket = brackets.get(i);
                break;
            }
        }
        // 税款计算
        return income.multiply(bracket.coeffR()).subtract(shares.multiply(bracket.coeffN())).intValue();
    }

// 用户在键盘上输入三项数据：married nbChildren salary
// 程序随后显示应缴税款
import tax.HardwiredTax;
import tax.ITax;

static final String SYNTAX = """
        syntax: Married NbChildren Salary
        Married: y for married, n for not married
        NbChildren: number of children
        Salary: annual salary in euros""";

void main() {
    // 创建 ITax 对象
    ITax tax = new HardwiredTax();

    // 输入循环
    while (true) {
        // 我们询问税款计算的参数
        String parameters = IO.readln("Tax calculation parameters in the format: "
                + "Married (y/n) NbChildren Salary, or nothing to stop: ");
        // 标准输入结束或空行：我们停止
        if (parameters == null || parameters.isBlank()) {
            break;
        }
        // 检查所输入行的字段数
        String[] fields = parameters.strip().split("\\s+");
        if (fields.length != 3) {
            IO.println(SYNTAX);
            continue;
        }
        // 检查参数的有效性
        // married
        String married = fields[0].toLowerCase();
        if (!married.equals("y") && !married.equals("n")) {
            IO.println(SYNTAX + "\nIncorrect married argument: type y or n");
            continue;
        }
        // nbChildren
        int nbChildren = positiveInteger(fields[1]);
        if (nbChildren < 0) {
            IO.println(SYNTAX + "\nIncorrect NbChildren argument: type a positive or zero integer");
            continue;
        }
        // salary
        int salary = positiveInteger(fields[2]);
        if (salary < 0) {
            IO.println(SYNTAX + "\nIncorrect salary argument: type a positive or zero integer");
            continue;
        }
        // 参数正确：我们计算税款
        IO.println("Tax=" + tax.calculate(married.equals("y"), nbChildren, salary) + " euros");
    }
}

// 返回字符串所表示的正整数或零，如果字符串不表示这样的数则返回 -1
int positiveInteger(String input) {
    try {
        int value = Integer.parseInt(input);
        return value >= 0 ? value : -1;
    } catch (NumberFormatException ex) {
        return -1;
    }
}
