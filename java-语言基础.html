    3. Java 语言基础

    3.1. 简介

    我们先把 Java 当作一种传统的编程语言来对待。类将在下一章讲解。一个程序由两部分构成：

    • 数据；
    • 操作这些数据的指令。

    我们通常力求把数据与指令分离：

    本章的所有示例都是紧凑源文件：即单个名为 [.java]的文件，没有 Maven 项目，使用命令 [java Basics01.java]运行。随后 [java]启动器在内存中编译该文件并执行它，不生成 [.class]文件。这一能力已在第 2 章“搭建开发环境”中介绍过。这些示例位于课程代码的 [03-basics]文件夹中。它们使用法语语言和惯例（即“区域设置”fr-FR）运行，就像在法语版 Windows 机器上一样。我们会看到，这只影响用特定 格式格式化的数字和日期：把浮点数简单转换为字符串时始终使用小数点。

    • 该文件不包含任何类声明——只有一个名为 [main]的方法。这是一个紧凑源文件 （Java 25）。编译器自行把文件内容包装进一个以文件名命名的隐式声明类中：[Basics01]。这一特性在 Java 21 到 Java 24 中以预览形式引入，之后在 Java 25 中成为正式特性；
    • 第 3 行：[main] 方法是程序的入口点：启动器 [java] 执行的就是这个方法。从 Java 25 起，它可以简单地写成 [void main()]，不带关键字 [public] 和 [static] ，也不带任何参数。方法体由花括号括起来；
    • 第 4 行：[IO] 类（Java 25）的 [println] 方法向屏幕写入一行；
    • 第 6 行：同一操作的传统形式。[System] 是一个类，[out] 是它的一个字段，表示标准输出（屏幕），[println] 是该对象的一个方法。[IO.println(x)] 只是[System.out.println(x)]的简写形式。我们会在紧凑文件中使用 [IO.println] ，在常规类中使用 [System.out.println] ，因为它遍布现有的 Java 代码；
    • 第 8 行：[List] 是字符串列表；列表将在第 5 章讲解。[List] 属于 [java.util]包：包 把相关的类组织在一起，就像文件夹把文件组织在一起。该类的全名是 [java.util.List]。由于该文件是紧凑文件，无需 import 语句即可使用它（见下文）；
    • 第 9 行：列表显示时，其元素用方括号括起来；
    • 每条语句以分号结尾；以 // 开头的行是注释，会被编译器忽略。

import java.util.Arrays;

public class Basics02 {
    // main 方法是程序的入口点
    public static void main(String[] args) {
        System.out.println("Hello world!");
        System.out.println("Number of arguments received: " + args.length);
        // 在普通类中必须导入 Arrays（java.util 包）
        System.out.println("Arguments: " + Arrays.toString(args));
    }
}

    说明：

    • 第 4 行：在 Java 中，所有代码都属于某个类。这里的类名为 [Basics02]。声明为 [public] 的类必须位于以该名称命名的文件中：[Basics02.java]；
    • 第 6 行：[main] 方法是程序的入口点。它是 [public] （可从类外部访问，特别是通过启动器 [java]），[static] （无需创建该类的对象即可执行），不返回结果（[void]），并通过数组 [args]接收命令行参数；
    • 第 8 行：数组 [args] 的元素个数是 [args.length]。这里的 + 运算符连接字符串和数字：数字首先被转换为字符串；
    • 第 10 行：[Arrays.toString]方法用数组的元素构造一个字符串。

    自 Java 25 起，[main]方法可以有四种形式：[static void main(String[] args)]、[static void main()]、[void main(String[] args)]、以及 [void main()]；如果一个类包含其中几种，启动器会优先选择带 [String[]]参数的那个。最后两种形式是实例方法：启动器先创建该类的一个对象，然后调用它的 [main]方法。关键字 [public] 不再是必需的。

    3.2.3. java.base 模块的自动导入

    程序 [Basics01.java] 使用了类 [List] ，却没有 [import java.util.List;]指令。这是可行的，因为编译器会自动在每个紧凑文件中添加如下指令（Java 25）：

    1
    import module java.base;

    表中的前八种类型，其名称以小写书写，是 Java 的基本类型。所有其他类型都是引用类型：类（[String]、[BigDecimal]、[Object]……），以及数组、枚举、接口和记录，我们稍后会讲到。两者的区别至关重要：

    • 基本类型的变量直接包含它的值；
    • 引用类型的变量包含对象的地址（即它的引用），对象本身存储在内存的其他位置。

    基本类型的值不是对象：它既没有字段，也没有方法。不过，每种基本类型在 [java.lang]包中都对应一个“包装类”：[Integer] 对应 [int]，[Double] 对应 [double]，[Character] 对应 [char]，依此类推。[Integer] 对象包装一个 [int]值。这些类还提供了有用的常量和方法：[Integer.MAX_VALUE]、[Integer.BYTES]、[Integer.parseInt]……自 Java 5 起，编译器会自动把基本类型转换为其包装类（装箱），反之亦然（拆箱）。因此，我们可以这样写：

    1
    String typeName = Integer.valueOf(3).getClass().getName();

    字面量 3 的类型是 [int]。由于它没有方法，我们不能写 [3.getClass()]：必须先用 [Integer]对象通过 [Integer.valueOf(3)]把它包装起来。每个对象都有一个 [getClass()] 方法，返回描述其类的对象；该对象的 [getName()] 方法返回类的全名，这里是 [java.lang.Integer]。

    除了 [char] 类型（16 位）之外，Java 没有无符号整数。不过，包装类提供了把整数的位解释为无符号数的方法：[Integer.toUnsignedString]、[Integer.parseUnsignedInt]、[Integer.compareUnsigned]、[Byte.toUnsignedInt]……它也没有基本的十进制类型：金额使用 [BigDecimal]类（位于 [java.math]包中）来计算，我们稍后会讨论它。

    3.3.3. 数据声明

    3.3.3.1. 声明的作用

    程序操作的数据以名称和类型为特征。这些数据存储在内存中。程序编译时，编译器根据程序员所作的声明，为每个数据分配一个以地址和大小为特征的内存位置。此外，这些声明还使编译器能够检测编程错误。因此，如果 [x] 是字符串，操作 [x = x * 2;] 就会被标记为错误。

    3.3.3.2. 常量声明

    在 Java 中，常量是用关键字 [final]声明的变量：它只能被赋值一次。语法如下：

    1
    final type name = value;

    在整个程序中使用的常量声明在方法之外，作为类的 [static final] 字段。例如：

    1
    static final double VAT_RATE = 0.2;

    为什么要声明常量？

    • 如果给常量起一个有意义的名称，程序更容易阅读；
    • 如果需要更改“常量”，程序更容易修改。因此，如果增值税税率改为 0.25，唯一需要修改的就是定义其值的语句：[static final double VAT_RATE = 0.25;]。如果在程序中显式使用了 0.2，就需要修改许多语句。

    按照惯例，在 Java 中，[static final] 常量的名称用大写字母书写，单词之间用 _ 字符分隔：[VAT_RATE]、[MAX_VALUE]。局部变量也可以声明为 [final]；在这种情况下，它保留常规名称。单词 [const] 在 Java 中是保留字，但并未使用。

    3.3.3.3. 变量声明

    变量由名称标识，并与数据类型相关联。Java 区分大小写：变量 [END] 和 [end] 是不同的。按照惯例，变量名以小写字母开头，其后每个单词以大写字母开头：[priceExclTax], [nbChildren]。

    变量可以在声明时初始化。声明一个或多个变量的语法是：

    1
    type variable1 = value1, variable2 = value2, ...;

    其中 [type] 是预定义类型或程序员定义的类型。初始化是可选的；不过，Java 不允许使用尚未赋值的局部变量（错误消息 [variable x might not have been initialized]）。

    自 Java 10 起，你还可以用关键字 [var] 代替类型，省略局部变量的类型：

    1
    var variable1 = value1;

    [var] 并不表示变量没有特定的类型：它的类型是编译器所确定的、赋给它的值的类型。这里必须初始化，编译器才能推断出类型。[var] 只能用于局部变量（不能用于字段或方法参数）。当类型从值上就能一目了然时，尤其是变量名很长时，可以使用它。

    3.3.4. 缺失的值：null、包装类和 Optional

    基本类型的变量，例如 [int]，总是包含一个值。有时需要能够表示值不存在：未知的年龄、数据库中的空字段。在这种情况下，我们使用包装类：类型为 [Integer] 的变量是一个引用，它可以是 [null]——也就是“没有对象”。

    事实上，任何引用类型的变量都可以取值 [null]：此时它不引用任何对象。尝试使用这样一个变量的成员——例如它的 [length()]方法——会导致运行时错误，即 [NullPointerException]：这是 Java 中最常见的错误。自 Java 15 起，错误消息会准确指出是哪个表达式的值为 [null]。Java 编译器不区分可能为 [null] 的引用和不可能为 null 的引用；诸如 JSpecify 项目中的注解（[@Nullable]、[@NonNull]）由分析工具使用，有助于弥补这一缺陷，但我们不会使用它们。

    为了表明某个方法可能什么也不返回，Java 8 增加了 [Optional<T>]类：[Optional<String>]对象是一个“盒子”，其中包含一个字符串，或者为空。它通过 [Optional.of(value)]、[Optional.empty()]、或 [Optional.ofNullable(valueOrNull)]创建；通过 [isPresent()]、[isEmpty()] （Java 11）、[get()]、[orElse(defaultValue)]……来查询。[OptionalInt]、[OptionalLong]、和 [OptionalDouble] 类对基本类型起同样的作用。

    3.3.6. 数据数组

    Java 数组是一个对象，可以把相同类型的数据归并在同一个标识符之下。它的声明如下：

    1
    Type[] array = new Type[n];

    [n] 是数组可以包含的数据元素个数。语法 [array[i]] 表示第 i 个数据元素，其中 i 属于区间 [0, n-1]。任何对数据项 [array[i]] 的引用，如果 i 不在 [0, n-1] 范围内，就会导致 [ArrayIndexOutOfBoundsException]异常。创建时，数组的每个元素都会被赋予其类型的默认值：数值为 0，布尔值为 [false] ，引用类型为 [null] 。数组可以在声明的同时初始化：

    1
        int[] integers = new int[]{0, 10, 20, 30};

    或者，在声明中更简单地写成：

    1
        int[] values = {0, 10, 20, 30, 40};

    数组有一个字段 [length] （不带括号），表示元素个数。数组创建之后不能改变大小：对于会增长的集合，要使用列表（第 5 章）。你还会遇到从 C 语言继承来的写法 [int integers[]]：它可以被接受，但不推荐。

    Java 没有真正的二维数组：带有两个下标的数组是一个数组的数组。声明

    1
    Type[][] array = new Type[n][m];

    创建一个包含 [n] 个元素的数组，其中每个元素都是对一个包含 [m] 个元素的数组的引用：[n] 行和 [m] 列。语法 [array[i][j]] 表示第 i 行的第 j 个元素。[array.length] 是行数，[array[i].length] 是第 i 行的元素个数。数组也可以在声明的同时初始化：

    1
        double[][] reals = {{0.5, 1.7}, {8.4, -6}};

    由于每一行都是独立的数组，各行的长度可以不同（这称为“阶梯数组”）。声明

    1
    Type[][] array = new Type[n][];

    创建一个包含 n 个元素的数组，其中每个元素都是一个一维数组的引用。上面的声明并不会初始化这些引用：它们的值为 [null]。

    Java 不提供从数组末尾开始计数的下标，也没有提取一段元素范围的记法。最后一个元素写作 [array[array.length - 1]]，而方法 [Arrays.copyOfRange(array, start, end)] 返回一个新数组，由下标从 [start]（含）到 [end] （不含）的元素组成。[java.util.Arrays]类还提供许多其他工具方法：[toString]、[deepToString]、[sort]、[fill]、[equals]、[copyOf]……更灵活的列表自 Java 21 起拥有 [getFirst()] 和 [getLast()] 方法。

    3.4.1. 写到屏幕

    有多种向屏幕写入的指令：

    1

3

    其中 [expression] 是可以转换为字符串以便在屏幕上显示的任何数据。所有 Java 对象都有一个 [toString()]方法用于完成这种转换；基本类型的值由 [String.valueOf]转换。[print]方法的作用与 [println] 相同，只是不换到下一行，而 [printf(format, value1, ...)]方法则以特定格式写出结果。

    [System]类提供对两个写入流的访问，即它的静态字段 [out] 和 [err]，类型为 [PrintStream]：

    • [System.out.println()] 写入流 [out]，即标准输出，它通常与屏幕相关联；
    • [System.err.println()] 写入 [err]流，即错误输出，它通常也与屏幕相关联。

    [IO]类（Java 25）提供了 [println] 和 [print]方法，它们写入 [System.out]。[out] 和 [err] 流可以在运行时重定向到文件，我们稍后会看到。

    3.4.5. 把表达式的值赋给变量

    这里我们关注的是 [variable = expression;]操作。表达式可以是算术、关系、布尔、字符串等各种类型。

    3.4.5.1. 赋值操作的解释

    操作 [variable = expression;] 本身就是一个表达式，其求值过程如下：

    • 计算赋值号右侧：结果是一个值 V；
    • 把值 V 赋给变量；
    • 值 V 同时也是该赋值的值，此时把赋值看作表达式。

    这就是操作 [V1 = V2 = expression] 有效的原因。由于 = 运算符从右到左求值，我们得到 [V1 = (V2 = expression)]。表达式 [V2 = expression] 被求值，其值为 V。它的求值使 V 被赋给 V2。接着下一个 = 运算符被求值为 [V1 = V]。该表达式的值仍然是 V；它的求值使 V 被赋给 V1。因此，操作 [V1 = V2 = expression] 是一个表达式，它的求值：

    • 使 [expression]的值被赋给变量 V1 和 V2；
    • 返回 [expression]的值。

    这可以推广到形如 [V1 = V2 = ... = Vn = expression]的表达式。

// value 的低 n 位，表示为由 0 和 1 组成的字符串
String binary(int value, int n) {
    StringBuilder bits = new StringBuilder();
    for (int rank = n - 1; rank >= 0; rank--) {
        bits.append((value >>> rank) & 1);
    }
    return bits.toString();
}

    3.4.5.7. 运算符的组合

    [a = a + b] 可以写成 [a += b]；[a = a - b] 可以写成 [a -= b]。运算符 /、%、*、<<、>>、>>>、&、|、^ 同样如此。因此，[a = a / 2;] 可以写成 [a /= 2;]。有一点小小的区别：组合运算符包含向变量类型的隐式转换。如果 [s] 是 [short]，[s = s + 1;] 会被拒绝（加法的结果是 [int]），而 [s += 1;] 则被接受。

    3.4.5.8. 自增和自减运算符

    记法 [variable++] 表示 [variable = variable + 1] 或 [variable += 1]。记法 [variable--] 表示 [variable = variable - 1] 或 [variable -= 1]。在表达式中使用时，这些运算符有两种形式：

    • [i++] （后缀）：表达式的值是自增之前i 的值；
    • [++i] （前缀）：表达式的值是自增之后i 的值。

    3.4.5.9. 三元运算符 ?

    表达式 [expr_cond ? expr1 : expr2] 的求值过程如下：

    • 先对表达式 [expr_cond] 求值。它是一个布尔表达式；
    • 如果它为真，表达式的值就是 [expr1]的值，并且不对 [expr2] 求值；
    • 如果它为假，则情况相反：表达式的值是 [expr2]的值，并且不对 [expr1] 求值。

    操作 [i = (j > 4 ? j + 1 : j - 1);] 在 j > 4 时把 j+1 赋给变量 i，否则赋 j-1。这与写 [if (j > 4) i = j + 1; else i = j - 1;] 相同，但更简洁。

    3.4.5.10. 空值：没有专门的运算符

    与 C# 或 Kotlin 等其他语言不同，Java 没有针对值 [null] 的专用运算符（替代值、对成员的条件访问）。我们改用：

    • 三元运算符 [a != null ? a : b]，或者 [Objects.requireNonNullElse(a, b)]方法（Java 9），如果 a 不等于 [null]，它就返回 a，否则返回 b。它用于赋一个后备值：[String name = Objects.requireNonNullElse(IO.readln(), "");]；
    • 简单的测试 [if (a == null) a = b;]，仅当变量等于 [null]时才给它赋值；
    • 类 *[Optional] 及其方法 *[map] ，仅当对象存在时才访问其成员：[Optional.ofNullable(text).map(String::length)] 在 [text] [Optional] 等于 [null]时返回空的 [Optional] ，否则返回包含文本长度的 Optional。

    3.5.1. 停止

    [System]类的 [exit]方法可以让你停止程序的执行：

    1

    3.6. 异常处理

    3.6.5. 受检异常和非受检异常

    这是 Java 的一个重要特性。异常是对象，它们的类构成一个层次结构：

    • 根类是 [Throwable]；
    • [Error] 类及其子类表示虚拟机的严重问题（[OutOfMemoryError]、[StackOverflowError]……），程序通常不会尝试捕获它们；
    • [RuntimeException] 类及其派生类（[NullPointerException]、[ArithmeticException]、[ArrayIndexOutOfBoundsException]、[IllegalArgumentException]、[NumberFormatException]……）通常表示编程错误或不正确的数据；
    • 从 [Exception] 派生的其他类（[IOException]、[InterruptedException]、[ParseException]、[SQLException]……）报告由程序环境引起的事件（文件缺失、网络中断、数据库宕机），正确的程序必须预见到这些事件。

    后一类异常称为“受检异常”：编译器会验证，能够抛出这类异常的方法——无论是直接抛出还是通过调用另一个方法——要么用 [catch]子句捕获它，要么用关键字 在其签名中声明它 [throws]：

    1
    String readFile(String name) throws IOException { ... }

    这样，责任就传递给了调用它的方法。派生自 [RuntimeException] 和 [Error] 的异常称为“非受检”异常：它们可以被捕获，但编译器并不要求这样做，也不需要声明它们。许多其他语言，例如 C# 或 Kotlin，只有非受检异常。

    3.9. 枚举

    枚举是一种数据类型，其值域由一组具名常量构成。设想一个需要处理考试成绩评语的程序。共有五种可能的评语：及格（Pass）、较好（Fairly Good）、良好（Good）、优秀（Very Good）和卓越（Excellent）。我们可以为这五个常量定义一个枚举：

    1
    enum Honours { PASS, FAIRLY_GOOD, GOOD, VERY_GOOD, EXCELLENT }

    按照惯例，常量的名称用大写字母书写。可以声明一个变量，使其取值来自该枚举：

    1
        Honours myHonours = Honours.PASS;

    可以使用 == 运算符把变量与枚举的各个可能值进行比较：

    1
2
3
        if (myHonours == Honours.PASS) {
        IO.println("Could do better");
    }

    与其他语言中枚举只是一组具名整数不同，Java 的枚举是一个类——派生自 [java.lang.Enum]类——它仅有的对象就是所声明的那些常量。每个常量都是一个唯一的对象，一次性创建；这就是它们可以用 == 比较的原因。每个常量都知道自己的名称（[name()]，或 [toString()]）以及它在声明中的序号（[ordinal()]，从 0 开始）。编译器会为每个枚举添加两个静态方法：

    3.10.1. 按值传递：Java 唯一的参数传递方式

    Java 只有一种参数传递方式：按值传递。实际参数的值被复制到对应的形式参数中。它们是两个不同的实体：如果方法修改了形式参数，实际参数保持不变。

    当参数是引用类型（数组、对象）时，被复制的值是引用：此时形式参数和实际参数引用同一个对象。因此，如果该对象是可修改的，方法可以修改它，调用方会看到这一变化；但是，方法不能使调用方的变量引用另一个对象。

    与其他语言不同，Java 不支持按引用传递，即形式参数和实际参数是同一个变量：方法不能修改其调用方的局部变量，也不能通过参数向调用方“返回”结果。我们改用：

    • 方法的返回值，由调用方把它赋给自己的变量；
    • 当方法需要返回多个值时，使用记录；
    • 作为参数传入的数组或可变对象，方法把结果放入其中。

    此外，声明为 [final] 的参数在方法内不能被赋予新值：这样编译器就确保它保持调用方传入的值。

    3.11. 局部函数和元组：Java 的解决方案

    3.11.1. 方法、lambda 和局部类

    有些语言允许定义局部函数——即写在另一个函数内部、只能在该上下文中使用的函数。Java 不允许这样做。在我们的紧凑文件中，文件里的方法起这个作用；在类中，我们编写私有方法。在方法内部，我们有两种工具可用：

    • lambda （Java 8），一种小型匿名函数，存放在合适类型的变量中，该类型称为函数式接口：[IntUnaryOperator cube = x -> x * x * x;]。lambda 在第 7 章“函数式接口、lambda 和事件”中讲解。lambda 可以读取其周围的局部变量，但前提是这些变量从不被修改（[final]变量或“实际上是 final”的变量）；它不能修改它们；
    • 局部类，声明在方法内部，只能在方法内使用。

    3.11.2. 用记录代替元组

    其他语言有元组，它们无需类型声明就能把多个值组合在一起。Java 没有元组：它使用记录 （Java 16）。声明 [record Couple(int number, String name) {}] 用一行创建一个类，其中每个对象由一个整数和一个字符串组成，同时还有一个构造函数、访问器方法 [number()] 和 [name()]，以及 [toString()]、[equals()]、和 [hashCode()]方法。记录可以在方法内部声明（局部记录）。可以使用记录模式（Java 21）提取它的组成部分，既可以配合 [instanceof]运算符，也可以在 [switch]中使用。记录是让方法返回多个值的自然方式；由于其组成部分有名称，它们比元组更易读。

void main() {
    // 精简文件的私有方法
    IO.println("square(7)=" + square(7));
    // 存储在变量中的 lambda（第 7 章）
    IntUnaryOperator cube = x -> x * x * x;
    IO.println("cube(3)=" + cube.applyAsInt(3));

    // lambda 不能修改局部变量：我们借助一个对象
    int[] counter = {0};
    Runnable increment = () -> counter[0]++;
    increment.run();
    increment.run();
    IO.println("counter=" + counter[0]);

    // 局部类：在方法中声明，只能在方法内使用
    class Accumulator {
        private int total;

        void add(int value) {
            total += value;
        }
    }
    Accumulator acc = new Accumulator();
    acc.add(5);
    acc.add(8);
    IO.println("total=" + acc.total);

    // 局部记录将若干具名值组合在一起
    record Couple(int number, String name) {}
    Couple t1 = new Couple(1, "one");
    IO.println("t1=" + t1 + ", t1.number()=" + t1.number() + ", t1.name()=" + t1.name());
    // 用记录模式解构（Java 21）
    Object object = new Couple(3, "three");
    if (object instanceof Couple(int number, String name)) {
        IO.println("number=" + number + ", name=" + name);
    }
    // 现成的键值对：Map.entry
    Map.Entry<Integer, String> pair = Map.entry(2, "two");
    IO.println("pair=" + pair + ", key=" + pair.getKey() + ", value=" + pair.getValue());

    // 返回多个值的方法：使用记录
    IntegerDivision d = divide(17, 5);
    IO.println("17 = 5 * " + d.quotient() + " + " + d.remainder());
    MinMax mm = minMax(new int[]{12, -4, 35, 7});
    IO.println("min=" + mm.min() + ", max=" + mm.max());

    // 交换两个变量：使用临时变量
    int a = 1, b = 2;
    int temp = a;
    a = b;
    b = temp;
    IO.println("a=" + a + ", b=" + b);
}

int square(int x) {
    return x * x;
}

record IntegerDivision(int quotient, int remainder) {}

record MinMax(int min, int max) {}

IntegerDivision divide(int a, int b) {
    return new IntegerDivision(a / b, a % b);
}

MinMax minMax(int[] values) {
    int min = values[0], max = values[0];
    for (int v : values) {
        if (v < min) min = v;
        if (v > max) max = v;
    }
    return new MinMax(min, max);
}
