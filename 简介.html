    1.1. 1995 年至 2026 年的 Java

    Java 由 Sun Microsystems 于 1995 年 5 月发布。它基于一个成就其成功的关键想法：[javac]编译器生成的不是机器码，而是一种中间代码——字节码——存放在[.class]文件中，由Java 虚拟机 （JVM，“Java Virtual Machine”）通过即时编译成机器码来执行。因此，同一个编译好的程序可以在 Windows、Linux 或 macOS 上运行：“一次编写，到处运行”。Kotlin、Scala 和 Groovy 语言同样生成字节码，并使用相同的库。

    重要里程碑：

    • 2006–2007 年：OpenJDK。Sun 以开源许可证发布了 Java 源代码（JDK）。目前所有的 Java 发行版都构建自 OpenJDK；
    • 2010 年：Oracle 收购 Sun，成为 Java 的主要贡献者；
    • 2014 年：Java 8，一个关键性的版本：lambda 表达式、Stream API、新的日期和时间 API。许多生产环境中的程序仍采用这种风格编写；
    • 自 2017 年（Java 9）起：Java 的新版本每六个月发布一次，分别在三月和九月。有些版本提供长期支持 （LTS，“Long-Term Support”）：Java 11（2018）、17（2021）、21（2023）以及 25（2025 年 9 月），本文档使用的就是它；从 Java 17 起，LTS 版本每两年发布一次。其他版本只获得六个月的支持；新特性往往先以“预览”形式出现，然后在后续版本中定稿；
    • JDK 由多家供应商发布，它们都基于 OpenJDK，就我们的目的而言是等价的：Oracle、Eclipse 基金会（Eclipse Temurin，Adoptium 项目）、Microsoft、Amazon（Corretto）以及各 Linux 发行版。

    本文档中的所有程序都由 JDK 25 的 [javac]编译器编译，使用启用全部警告的 [-Xlint:all]选项，编译时没有任何错误或警告，并使用附录中列出的库版本运行。本文档中重现的结果就是这些执行的结果。第 2 至 4 章的结果是在法语语言和地区设置（fr-FR）下得到的，就像在法语版 Windows 系统上一样：格式化的浮点数以小数逗号显示，日期为法语；后续各章则在英语设置下运行（小数点、英语日期）。有两点说明：

    • JDK 的错误消息（异常消息、编译器消息）是英文的：JDK 没有提供它们的法语翻译；
    • 这些示例是在 Linux 上运行的。在大多数情况下这没有区别：Java 是跨平台的。少数差异（使用 / 而不是 \ 的文件路径、终端命令）会在出现之处注明。

    多线程、异步或网络程序的结果，以及测得的执行时间，每次运行可能有所不同：注释侧重于可重现的内容。
